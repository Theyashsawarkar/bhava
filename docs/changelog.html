Changelog

Every change to bhava, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.4.02026-11-09release ↗

  • The category rail uses Vyom's new side-rail slot (build_rail(), tabs_in_rail) instead of reaching into the panel's widgets.
  • Space u p (show or hide the preview) now comes from Vyom core, which also remembers it.
  • Vim keys (Vyom 0.7, ADR 0008): NORMAL and INSERT modes, Space as the leader with a which-key strip, ? and Space ? list every key, Space Space is a palette, counts (5j), gg / G, H / L for tabs. It opens in INSERT (search-first): type, then Esc for NORMAL. Needs Vyom 0.7.0.
  • Its keys are data (bhava/vim.py); scripts/keybinds.py writes the # keybind: lines and the README's key tables from them, and --check (CI) fails when they drift.
  • Its own mode machinery is gone: the mode pill, the keys typed so far, counts and gg / G are Vyom's now (the category rail stays). H / L switch categories (w / b still do), Space t 1..9 jumps to one, Space y c copies the shortcode, Space d d removes an emoji from Recent, Space u p hides the preview.
  • Ctrl+C in INSERT copies the search box's text again (y copies the emoji).
  • A note in the footer (copied, removed from Recent, no skin tones) clears itself after a few seconds, so the footer's keys come back.

v0.3.22026-11-08release ↗

  • The category rail shows names only, no numbers (Ctrl+1..9 still picks one; the tooltip says which).

v0.3.12026-11-08release ↗

  • The footer's NORMAL / INSERT keys come from Vyom's tab_hints() (Vyom 0.6.2), so a status message takes their place instead of being squeezed beside them.

v0.3.02026-11-07release ↗

  • Vim modes. It opens in INSERT, where typing searches as before. Esc goes to NORMAL: h j k l move in the grid, with a count (5j, 3l); w / b change category; gg / G first / last; 0 / $ start / end of the row; Ctrl+D / Ctrl+U half a page; Enter types, y copies, t or s changes the skin tone; i, a or / (a new search) go back to INSERT; q or Esc closes, so Esc twice closes. A pill in the footer says NORMAL (accent) or INSERT (green), with a half-typed count or g beside it, and the search box goes quiet in NORMAL. [plugin.bhava] start_mode = "normal" opens in NORMAL.
  • A new look: bigger emoji on a calmer grid, the selected one framed in the accent colour; the categories in a rail on the left with their names and numbers; a "found" count while you search.
  • The skin tone is now remembered per emoji, chosen with a visible picker in the preview (Ctrl+T cycles it). Your old single setting is the starting tone for the rest.
  • The preview shows the name, the :shortcode: and the keywords, the words your search matched in peach, and "Type it" (Enter) and "Copy" buttons with their keys.
  • Ctrl+C copies the emoji (Ctrl+Enter still does).
  • Choosing a category while searching clears the search, so the category shows.
  • Needs Vyom 0.6.0.
  • Every corner is rounded: the website's callouts.
  • A logo and a shloka at the top of the README and the website: every Vayu tool has them now.

v0.2.02026-10-24release ↗

  • Category tabs switch like every Vyom tool's tabs (Vyom 0.3.0): Ctrl+H / Ctrl+L for the previous / next category, Ctrl+1..9 and Ctrl+0 by number. The numbers moved by one: Ctrl+1 is Recent, Ctrl+2 All, Ctrl+0 Symbols (was Ctrl+0 Recent); Flags is Ctrl+H from Recent. Needs Vyom 0.3.0.

v0.1.42026-10-21release ↗

  • A website (GitHub Pages, https://theyashsawarkar.github.io/bhava/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.32026-10-21release ↗

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.22026-10-19release ↗

  • Opens at Vyom's shared panel size (Vyom 0.2.5) like every other tool: its own width/height are gone.

v0.1.12026-10-19release ↗

  • Keys are spelled out (Ctrl+Enter, Shift+Enter, Backspace) instead of symbols (⌃↵, ⇧↵, ⌫) in the footer and on rows and buttons.

v0.1.02026-10-19release ↗

  • First release, as its own repository: the emoji picker. Replaces wofi-emoji in Vayu.
  • Every Unicode 16 emoji in a grid, your recent ones first.
  • A tab per category, and one skin-tone setting (Ctrl+T) applied to every emoji that has tones.
  • A big preview with the name, shortcode, code points and keywords.
  • Enter types the emoji into the window you were in (and copies it); Ctrl+Enter only copies.
  • Names and groups from Unicode's emoji-test.txt, keywords from wofi-emoji (MIT): see NOTICE and tools/build-data.py.
