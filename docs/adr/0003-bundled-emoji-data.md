# 3. Bundle the emoji data, generated from Unicode

**Status:** Accepted  
**Date:** 2026-10-19

## Context

Emoji pickers that depend on a system package break when it lags behind Unicode or isn't installed; downloading at run time needs a network.

## Decision

`bhava/emoji.json` is generated by `tools/build-data.py` from Unicode's emoji-test.txt (names, groups) and wofi-emoji's keywords (MIT), and committed.

## Consequences

- Works offline, the same everywhere.
- New Unicode versions mean rerunning the script.
